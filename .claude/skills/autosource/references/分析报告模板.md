# 领域分析报告模板

> 收尾最后一步（阶段 6）按本模板生成领域分析报告，Write 到输出目录根的 `分析报告.md`。
> 本报告的定位：数据源是输入，领域洞察是产出。

## 固定模板

严格按以下固定模板（`{领域词}` 与 N 替换为实际值）：

```markdown
# {领域词} 领域分析报告
> 本报告基于本次自动发现的 N 条数据源生成；领域判断为模型解读，不保证事实准确。

## 一、领域概览
（领域定义、边界、规模特征——从拆解树与来源密度归纳）

## 二、技术格局
（主要技术方向与路线——从节点树结构与各子领域来源分布推导）

## 三、产业生态
（主要玩家与格局，国际 vs 国内——从清单中厂商来源的名单与分布推导）

## 四、标准与规范体系
（该领域的标准框架如何组织——从标准类来源归纳）

## 五、中文与国际生态对比
（两侧数据源生态的差异——清单语言分布与领域知识）

## 六、趋势观察
（来源密集/稀疏的子领域所暗示的热点或短板——节点间候选数对比）
```

## 写作纪律

1. **依据锚定**：每段结论尽量标明依据（如"从 XX 节点的 XX 来源可见"），判断须能追溯到本次清单
2. **事实守界**：引用的数字与来源名称必须来自本次实际产物，禁止编造
3. **不堆砌统计**：数字属于 stats.csv，本报告负责解读与判断
