## 阶段 3 · 验证搜索

阶段 0/2 的产出即本阶段输入：

```
领域词: 交换机
叶子节点:
  - 数据中心交换机
  - 企业园区交换机
  - ...
知识清单:
  - {名称: IEEE 802.3 以太网工作组, 节点: 以太网标准(IEEE 802.3), 预期体裁: 行业标准}
  - {名称: Cisco Nexus 文档体系, 节点: 数据中心交换机, 预期体裁: 官方文档}
  - ...
```

- **查询词构造**：按来源实际情况自由组合（每词 2-4 个组件），组件池——**来源识别（必带其一）**：原名 / 英文名 / 缩写 / 别名；**入口意图**：官方文档 / 官网 / 入口 / 目录 / 数据库 / 标准列表 / 仓库；**辅助**：领域词、地域词和语言词。组合示例：`中国电子技术标准化研究院 交换机 标准`、`IEEE 802.3 Ethernet Working Group official`、`SONiC open source networking documentation`、`CCSA 通信行业标准 检索`。若清单项所属叶子节点有节点搜索画像，可按需加入该节点的核心搜索词、相关来源类型或来源角色，但不要求每次查询全部加入。
- **首轮优先官方入口**：验证搜索的目标是官方入口 URL——首轮查询词优先用"来源识别 + 官网 / 官方文档"（如 `中国通信标准化协会 官网`、`ETSI official documentation`）；暂不使用"来源识别 + 具体体裁词"（如 `中国电子技术标准化研究院 白皮书`）——这类词易命中低相关结果。
- **每项固定搜 2 次，两次取不同角度**：两次查询词不得重复，在组件池内换来源识别或入口意图词，语言随之适配。两次结果里的候选全部按收录判据处理，不只取验证目标那一条。
- **落空处理**：两次都没搜到官方入口 → 标记未验证，留扩量轮换角度重试（阶段 5）
- **通过标准（按条目粒度对应）**：目标始终是该机构的官方入口 URL；搜不到入口时按以下标准降级处理，扩量轮换"官网/官方文档"角度兜底。
  - 合集级清单项：搜索结果中出现该机构的**入口 URL**（官网首页 / 根域名（含语言首页） / 文档门户 / 目录 / 列表页）即通过。**以下不算入口**：帮助页 / FAQ / 政策条款页 / 单篇 PDF / 新闻公告页 / 课程页 / 机构介绍页 / 带跟踪或翻译参数的 URL（`?utm_`、`?trk=`、`?_x_tr_sch=` 等）——落在这些形态上按"未通过"处理，换角度重试
  - 合集级清单项只搜到合集内**单篇载体**（PDF、单条 KB 等）：**不算通过**——按"未通过"落库（note="仅找到单篇载体"），扩量轮换角度专找入口（如 `{机构名} documentation`）；换角度仍找不到入口 → **定案时以该单篇通过**（granularity 单篇级），reason 注明"仅找到单篇载体，未找到合集入口"
  - 单篇级清单项：搜索结果中出现**该载体本身**即通过
  - 连单篇载体都没有 → 标记未验证，留待扩量轮换角度重试后按阶段 5 定案
- **通过后**：在**清单项内**填上 `category_path（完整路径）/ source_type / granularity / url / description / reason`（URL 照抄），预期体裁允许按实际形态修正——核对结果用 **record_knowledge 分批落库**（每 ~10-15 项一批，与 record_search 同节奏；verified=true 项 URL 入库即验证据链）
- **未通过**：**当场**用 record_knowledge 落库 `verified=false` + note——**note 按当次搜索结果如实取一个：`未找到官方入口` / `仅找到单篇载体` / `疑似无效机构`**；不急于分类，扩量轮换角度重试后按阶段 5 定案（改判时同名重录即状态更新）。**未通过项必须当场落库，不得攒到定案时再记**——会话中断时未落库的核对结果会整体丢失
- **搜索日志记录**：每 ~10-15 次验证搜索调用一次 record_search 批量入库——验证搜索项 `phase/node/query/results/extracted`（**phase 只允许三个取值：验证搜索 / 增量发现 / 扩量轮**；**extracted 只记顺路新源数，验证通过本身不计入**）；增量发现项同此格式。query 照抄实际发出的查询词——逐条记、批量入，不要每次搜索单独调用
- **阶段中途不与用户交互**：不产出状态汇报、不请用户选择方向（含"是否继续 / 是否缩小领域"）——本阶段做完即进入阶段 4
