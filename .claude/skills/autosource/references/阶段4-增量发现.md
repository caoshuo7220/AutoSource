## 阶段 4 · 增量发现

**谁执行**：本阶段的搜索、提取与落库**整体下放子代理**（每 1 节点一组共 20 次搜索，派工模板见通用纪律"子代理派工"）——主流程不自己搜，只按阶段派工、收齐回执。

**搜索次数**：每节点**固定 20 次**搜索（基底 16 次 + 扩充 4 次）：

- **固定 4 次**（组织形式类中文/英文各 1 次，体裁类中文/英文各 1 次）：各取与节点最相关的一个词
- **自由 8 次**（仅中文搜索词）：从角度池选 8 个**本节点尚未覆盖的角度**各搜一次，优先覆盖不同的来源类型和来源角色，避免在同类角度上重复换词
- **实体 4 次**（本节点搜索过程中新发现的实体）：从中选 4 个，按下方"实体选题"构造规则各搜一次入口；清单或厂商清单中已列出的机构不算新实体；新实体不足 4 个时，空缺次数退回角度池补角度
- **扩充 4 次**（角度池或实体选题均可）：基底 16 次完成后固定执行，不设续批判定、不做产出门槛，做完即进入阶段 5。**与阶段 5 扩量轮区分**：扩充是基底后的延续（每节点必经），扩量轮是阶段 5 对薄弱节点的定向补搜——两者不是一回事，扩充不得并入扩量轮执行。

**角度池**（包括但不限于）：

- 学术类：论文 / 专利 / 文献库
- 组织形式类：列表 / 排名 / 数据库 / 标准 / 仓库 / 合集
- 体裁类：官方文档 / 开发者文档 / 手册 / 知识库 / API 参考 / 帮助中心 / 白皮书 / 市场研究
- 数据类：数据集 / 开放数据
- 生态类：社区（含开源项目社区与邮件列表）
- 来源角色类：标准组织 / 监管机构 / 政府部门 / 行业协会 / 厂商 / 研究机构 / 大学 / 评测机构 / 基金会 / 公共数据平台

**易失效词形（两类已知易命中低相关结果集的模式）**：① **标准**角度词单独使用（缺领域词 + 入口词）会命中标准平台首页——必须组合"领域词 + 入口词"（检索 / 列表 / 分类 / 目录 / 合集）；**论文、专利角度不受此限**：它们的目标就是单篇技术文件的内容页（IEEE / arXiv / 知网 / 万方的论文页、Google Patents 的专利页），**命中即按单篇级收录**，只有平台首页与整体无关的批次才零提取；② 英文查询词以 `list / standard list / paper list / market report / directory` 等未组合泛化后缀结尾会命中书店页、股票新闻、手册镜像站——优先组合"领域词 + 厂商内容入口词"（documentation / official docs / datasheet / support / products），尽量避免 directory / registry / collection 这类泛化目录词。

- **查询词构造**（两类选题）：
  - **框架内角度**（角度池）：围绕当前节点名称或节点搜索画像中的核心搜索词，组合一个发现型角度词，优先使用该节点适用的来源类型或来源角色；查询词必须包含领域词（或节点核心词），角度词尽量带入口词；次数与语言分配见上方"搜索次数"；必须带发现型词汇；画像中的机构名称不是必须逐一搜索的清单——以上约束只管本类。
  - **实体选题**（新发现的实体）：对与本节点强相关的实体（机构 / 厂商 / 产品 / 规范等具体对象），用"实体名 + 入口词"作查询词（如 `超以太网联盟 UEC 规范`），**可不含领域词/节点核心词**；搜索目标是该实体的成体系载体入口，不单独搜规格参数页；命中结果的收录按通用纪律"收录判据"执行。清单或厂商清单中已列出的机构不在本类范围内，本类主要用于增量发现中新出现的机构。
- **提取纪律**：全量提取、URL 逐字照抄、每条带 reason、遵守收录判据与标注规则
- **记录时机（group commit）**：基底 16 次搜索完成后，把该节点新增条目用一次 record_sources 入库、16 条搜索记录用一次 record_search 入库；扩充 4 次完成后再各入一次（每节点合计 20 条搜索记录）——两个批量调用一组，不要每次搜索后逐条调用。批量大小 = 单节点批次量（约 15-25KB），远离截断边界；入库后该节点内容即由脚本持有，会话压缩也不丢失。**提取为 0 的搜索行必须带 `zero_reason` 拒收理由**；如实记录，不得谎报次数
- **入库前自查**：入库前先算本节点提取率（收录条数 ÷ 搜索次数）；明显低于 1 条/搜时，回头重审零提取搜索的结果（重审不重新搜索），确认漏收补调 record_sources 后再入库
- **阶段中途不与用户交互**：不产出状态汇报、不请用户选择方向（含"是否继续 / 是否缩小领域"）——本阶段做完即进入阶段 5
