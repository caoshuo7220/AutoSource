# AutoSource Skill 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 创建一个 Claude Code Skill——用户输入 `/autosource <领域>`，Claude 在对话中自动完成领域拆解、Web 搜索、数据源整理、去重校验、导出 JSON/CSV 全流程。

**Architecture:** 一个 `SKILL.md`（流程指令 + 输出约束）+ 一个 `postprocess.py`（去重 + URL 可达性校验）。Claude Code 自身提供推理、web_search、read/write/bash 能力；SKILL.md 定义流程和规范；postprocess.py 处理需要确定性逻辑的去重和 HTTP 校验。

**形式:** Claude Code Skill（`.claude/skills/autosource/`），通过 `/autosource` 斜杠命令触发。

## 文件结构

```
.claude/skills/autosource/
├── SKILL.md           ← 核心：流程指令、拆解原则、输出规范、使用说明
└── postprocess.py     ← 辅助：URL 去重 + HTTP 可达性校验脚本（~60 行）
tests/
├── __init__.py
└── test_postprocess.py
```

**接口关系：**

```
用户输入: /autosource 算力服务器 [-c GPU服务器 CPU服务器] [-t 数据集 产品文档]
    ↓
Claude 加载 SKILL.md → 按指令执行:
    1. 构建拆解 prompt → web_search 逐节点搜索
    2. 整理为结构化 JSON → write 到文件
    3. bash: python .claude/skills/autosource/postprocess.py <input>.json <output>.json
    4. 汇总结果返回用户
```

## 全局约束

- Skill 安装在 `.claude/skills/autosource/` 目录
- `/autosource` 命令接收领域描述（必填）+ 可选 `-c` 分类路径 + 可选 `-t` 类型限定
- 输出 JSON（含完整元数据）和 CSV（中文表头）两种格式
- 输出文件放在当前工作目录，命名规则：`{领域}.json` / `{领域}.csv`
- postprocess.py 依赖仅标准库 + `requests`，用户需预装（`pip install requests`）
- 搜索使用 Claude Code 自带的 web_search 工具

`.claude/skills/autosource/SKILL.md`:
```markdown
---
name: autosource
description: 输入领域描述，自动发现该领域的公开数据源并导出结构化清单。
---

# AutoSource — 数据源自动发现

当用户输入 `/autosource <领域描述>` 时，执行以下流程。

## 参数

| 参数 | 必填 | 说明 |
|------|------|------|
| `<领域描述>` | 是 | 粗粒度文本，如 `算力服务器` |
| `-c` | 否 | 预设分类路径，如 `-c "GPU服务器" "CPU服务器"` |
| `-t` | 否 | 限定数据源类型，如 `-t "数据集" "产品文档"` |

## 执行流程

### 1. 领域拆解（用户未指定 -c 时执行）

将领域拆解为树状分类结构。遵循以下原则：

- 层级清晰：上下级严格包含，同级互斥不重叠
- 符合领域常识：分类体系与该领域公认知识体系一致
- 符合业务逻辑：粒度匹配实际使用场景，不过细也不过粗
- 深度自适应：不同领域层级数可不同（如金融可能 4 层，开源框架可能 2 层）
- 覆盖完整：覆盖该领域主要方向，无明显遗漏

将拆解结果以树形文字展示给用户。

### 2. 数据源搜索

对每个叶子节点进行 web_search。策略：

- 每个节点构造合适的搜索关键词（覆盖中英文）
- 若首次搜索无结果，更换关键词至少 2 次重新搜索
- 若更换后仍无结果，该节点标记为"无数据源"
- 检查各节点覆盖是否均匀，对薄弱节点扩量搜索
- 终止条件：各节点均有代表性条目，且继续搜索不再显著增加新有效条目

### 3. 结果整理

将搜索到的数据源整理为结构化 JSON，每条包含以下字段：

```json
{
  "name": "数据源官方标准名称",
  "category_path": "以 - 分隔的层级分类路径",
  "source_type": "内容体裁（如：技术博客、产品文档、专业书籍、专利论文、开源仓库、数据集、排行榜/基准、行业标准、资讯平台等）",
  "url": "数据源主入口 URL",
  "description": "1-2 句话说明内容与核心价值"
}
```

约束：
- name 和 url 不可为空
- 同一数据源只出现在一条分类路径下
- 分类路径术语统一，同一概念不出现多种表述
- 仅收录公开可访问的数据源，不含需账号、付费、非公开的

将 JSON 写入文件 `{领域}.json`（领域名中的空格替换为 `_`）。

### 4. 后处理

执行去重和 URL 校验脚本：

```bash
python .claude/skills/autosource/postprocess.py {领域}.json {领域}_clean.json
```

脚本完成：
- 域名 + 数据源名称联合去重（镜像站保留）
- HTTP HEAD/GET 校验 URL 可达性（超时 5s，重试 1 次）
- 输出清洗后的 JSON，并打印统计信息

将脚本的统计输出展示给用户。

### 5. 导出 CSV

读取清洗后的 JSON 文件 `{领域}_clean.json`，按以下表头生成 CSV：

```
数据源名称, 分类路径, 数据源类型, 访问地址, 简要说明
```

编码 UTF-8 BOM（兼容 Excel 直接打开）。写入 `{领域}.csv`。

### 6. 汇总报告

向用户展示汇总：

```
领域: {领域描述}
分类树: {拆解结果}
共发现: X 条
有效 URL: Y 条 (Z%)
无效/移除: N 条
无结果节点: {列表或"无"}
输出文件:
  JSON: {path}
  CSV:  {path}
```

## 效果数据

每次执行完成后，在输出 JSON 同级目录写入 `{领域}_stats.json`，记录：

```json

  "domain": "领域描述",

  "empty_nodes": ["无结果的节点列表"],

}
```

`.claude/skills/autosource/postprocess.py`:
```python
"""AutoSource 后处理脚本：去重 + URL 可达性校验。

用法:
    python postprocess.py input.json output.json

从 input.json 读取数据源列表，去重后校验 URL，将有效条目写入 output.json，
统计信息打印到 stdout。
"""

import json
import sys
from urllib.parse import urlparse
from pathlib import Path


def _domain(url: str) -> str:
    return urlparse(url).netloc


def deduplicate(sources: list[dict]) -> list[dict]:
    """按域名 + 名称去重，保留首次出现，镜像站（不同域名）保留。"""
    seen: set[tuple[str, str]] = set()
    result: list[dict] = []
    for s in sources:
        key = (_domain(s["url"]), s["name"])
        if key not in seen:
            seen.add(key)
            result.append(s)
    return result


def check_url(url: str, timeout: int = 5, max_retries: int = 1) -> bool:
    """校验单个 URL 的可达性（HEAD 优先，失败回退 GET）。"""
    import requests

    for _ in range(max_retries + 1):
        try:
            resp = requests.head(url, timeout=timeout, allow_redirects=True)
            resp.raise_for_status()
            return True
        except requests.RequestException:
            try:
                resp = requests.get(url, timeout=timeout, stream=True)
                resp.raise_for_status()
                resp.close()
                return True
            except requests.RequestException:
                continue
    return False


def process(input_path: str, output_path: str) -> dict:
    """执行完整后处理流程，返回统计信息。"""
    data = json.loads(Path(input_path).read_text(encoding="utf-8"))

    total = len(data)
    unique = deduplicate(data)
    removed = total - len(unique)

    valid: list[dict] = []
    invalid_urls: list[str] = []
    for s in unique:
        if check_url(s["url"]):
            valid.append(s)
        else:
            invalid_urls.append(s["url"])

    Path(output_path).write_text(
        json.dumps(valid, ensure_ascii=False, indent=2),
        encoding="utf-8",
    )

    stats = {
        "total": total,
        "removed_duplicates": removed,
        "checked": len(unique),
        "valid": len(valid),
        "invalid": len(invalid_urls),
        "valid_ratio": round(len(valid) / max(total, 1), 3),
        "invalid_urls": invalid_urls,
    }
    return stats


def main() -> None:
    if len(sys.argv) != 3:
        print("用法: python postprocess.py <input.json> <output.json>", file=sys.stderr)
        sys.exit(2)

    in_path, out_path = sys.argv[1], sys.argv[2]

    if not Path(in_path).exists():
        print(f"错误: 输入文件不存在: {in_path}", file=sys.stderr)
        sys.exit(1)

    stats = process(in_path, out_path)

    print(f"去重: {stats['total']} → {stats['checked']} (移除 {stats['removed_duplicates']} 条重复)")
    print(f"URL 校验: {stats['valid']}/{stats['checked']} 有效 ({stats['valid_ratio']:.0%})")
    if stats["invalid_urls"]:
        print(f"无效 URL:")
        for u in stats["invalid_urls"]:
            print(f"  - {u}")
    print(f"输出: {out_path}")


if __name__ == "__main__":
    main()
```
