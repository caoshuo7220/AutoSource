# AutoSource Skill 实施计划

> 本计划已执行完成。文档保留作为架构和维护参考。

**Goal:** 创建一个 Claude Code Skill——用户输入 `/autosource <领域>`，Claude 在对话中自动完成领域拆解、Web 搜索、数据源整理、去重校验、导出 CSV 全流程。

**Architecture:** 一个 `SKILL.md`（流程指令 + 输出约束）+ 一个 `postprocess.py`（去重 + URL 可达性校验）+ 一个 `settings.json`（权限分发）。Claude Code 自身提供推理、web_search、read/write/bash 能力；SKILL.md 定义流程和规范；postprocess.py 处理需要确定性逻辑的去重和 HTTP 校验；settings.json 让使用者在 clone 后一次确认即可无弹窗运行。

**形式:** Claude Code Skill（`.claude/skills/autosource/`），通过 `/autosource` 斜杠命令触发。

## 文件结构

```
.claude/
├── settings.json                         ← 项目级权限（WebSearch/Bash/Write 等，Git 跟踪分发）
└── skills/autosource/
    ├── SKILL.md                          ← 核心：流程指令、拆解原则、输出规范
    └── postprocess.py                    ← 辅助：URL 去重 + HTTP 可达性校验脚本
tests/
├── __init__.py
└── test_postprocess.py                   ← 9 个单元测试，全部通过
docs/
├── 需求文档.md
└── 实施计划.md
```

**用户输入输出：**

```
输入: /autosource "帮我收集AI训练GPU算力服务器相关数据源"
  ↓
Claude 按 SKILL.md 执行:
  1. 提炼领域词 → "算力服务器"
  2. 领域拆解 → 树状分类
  3. 逐节点 web_search（每个叶子节点至少搜索一次）
  4. 整理为结构化 JSON 写入 outputs/{领域词}_{时间戳}/raw.json
  5. 自动检测并安装 requests → 运行 postprocess.py 去重+URL 校验
  6. 导出 CSV → outputs/{领域词}_{时间戳}/数据源清单.csv
  7. 清理中间 JSON + 写入 stats.json + 汇总报告
```

## 全局约束

- Skill 安装在 `.claude/skills/autosource/` 目录
- `/autosource` 命令接收领域描述（必填）+ 可选 `-c` 分类路径 + 可选 `-t` 类型限定
- 最终交付物：CSV（UTF-8 BOM，中文表头），放在 `outputs/{领域词}_{时间戳}/数据源清单.csv`
- 同领域多次运行不覆盖（时间戳区分）
- 领域词由系统从用户输入中提炼为 2-6 字核心关键词，不等同于用户原始输入
- postprocess.py 依赖仅标准库 + `requests`，SKILL.md 流程中自动检测并按需安装
- 搜索使用 Claude Code 自带的 web_search 工具
- 权限通过 `.claude/settings.json` 随仓库分发，用户首次 clone 后确认一次即可

## 已完成的 Tasks

### Task 1: SKILL.md（核心流程定义）

- 定义了 `/autosource` 命令的完整 6 步执行流程
- 包含：领域词提炼、拆解原则、搜索策略（逐节点强制搜索）、JSON 中间格式约束、后处理调用、CSV 导出规范、汇总报告格式、效果数据记录

### Task 2: postprocess.py（后处理脚本）

- `deduplicate()`：按域名 + 数据源名称联合去重，镜像站保留
- `check_url()`：HTTP HEAD 优先，失败回退 GET，超时 5s，重试 1 次
- `process()`：完整流水线，返回统计信息字典
- 9 个单元测试覆盖全部功能

### 权限配置

- `.claude/settings.json`：项目级权限白名单（WebSearch、Write/Read/Edit、Bash），随 Git 分发
- `.claude/settings.local.json`：个人本地配置，Git 忽略
